# 32_system-engineering-resources 인수인계

## 1. 재개 경로

실제 Git 루트·branch·변경과 기존 AGENTS를 확인한 뒤 [INDEX](INDEX.md)에서 필요한 자료를 선택합니다. 현행 상태는 [TODO](../TODO.md), 단계·복구는 [PLAN](../PLAN.md), 원인·조건은 [ISSUE](ISSUE.md)에서 읽습니다.

## 2. 전달할 근거

작업 ID·담당 파일·승인 범위·기존 변경·실행·검증·미실행·결과 링크·다음 조건·복구 자료·게시 여부를 연결합니다. 초기 후보 작성 시점의 관찰을 현재 세션의 적용·검증 결과로 재사용하지 않습니다.

## 3. 완료와 한계

실제 검사 기준은 [검증](verification.md), 완료 근거는 [이력](../CHANGELOG.md)에 둡니다. 현장 변경과 private 원문을 보존하며 중앙 profile의 초기 상태로 덮어쓰지 않습니다. 실제 대상 적용은 이번 신규 profile 작성 범위에 포함하지 않았습니다.
