## 3. 사전 결정 규칙

되돌릴 수 있는 작은 일(기록 추가·문서 정정·상태 갱신)은 묻지 않고 수행하고, 사후 보고에 근거와 되돌릴 commit을 적습니다. [검증](verification.md)의 검사가 모두 0건이고 원격 뒤처짐이 0이며 담당 파일만 포함할 때 push까지 진행합니다. 파일 이동·지침 개정·삭제는 실행 전에 사용자에게 묻습니다.

직접 요청: 다른 Claude 세션·저장소는 05 총괄을 거치지 않고 형식 B로 작업 ID·바라는 문서·근거를 적어 요청할 수 있습니다. 받을지와 순서는 이 세션이 정하고 [TODO](TODO.md)에 작업 ID와 요청 세션을 적습니다. 이 저장소는 공개 저장소이므로 요청 세션의 비공개 정보(IP·호스트명·접속 정보·계정·경로, 비공개 저장소의 프로젝트 내부 이름·구성, 비공개 문서 문장)는 옮기지 않습니다. 직접 요청으로 만든 새 문서와 내용 변경의 commit·push는 이 세션 사용자 확인 뒤에 합니다. 여러 저장소 규칙·공통 정책에 닿거나 사용자 결정이 필요한 요청은 05 총괄로 돌리고, 05 배정(결정 ID 있음)과 겹치면 05 배정을 먼저 합니다. Codex 요청은 해당하지 않습니다(POLICY-31 상호 검토). 05 총괄은 직접 요청 건을 대조하지 않습니다(05 D169).
