# Claude Tool Mirror

Claude 관련 Skill과 운영 자료를 추가하기 위한 예약 영역입니다.

현재는 원본 경로와 공개 동기화 허용 목록을 확정하지 않았습니다. 자료를 추가할 때 Claude 실행 환경, 공개 가능한 파일, 제외 대상, 동기화 방향을 별도 정책으로 정의합니다.

공통 저장소 운영 정책은 [Repository Governance](../01_repository_governance/README.md)를 참고합니다.
