# Claude Tool Mirror

Claude 관련 Skill과 운영 자료를 추가하기 위한 예약 영역입니다.

현재는 원본 경로와 공개 동기화 허용 목록을 확정하지 않았습니다. 따라서 이 디렉토리는
예약 영역이며 실제 Claude 파일, manifest와 동기화 스크립트를 추가하지 않습니다.

활성화 조건은 [31 governances 동기화 정책](https://github.com/siasia86/31_governances/blob/yunli/.governance/repository/sync_policy.md)의 새 도구 미러
활성화 조건을 따릅니다. 원본 경로, 공개 allowlist, 제외 범위, 단방향 동기화 절차,
검증 방법과 관리 책임을 모두 확인한 뒤에만 활성화합니다.

공통 저장소 운영 정책은 [31 governances Repository Governance](https://github.com/siasia86/31_governances/blob/yunli/.governance/repository/README.md)를 참고합니다.
