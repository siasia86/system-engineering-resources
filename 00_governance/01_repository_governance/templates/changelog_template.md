# CHANGELOG Template

완료된 변경을 루트 `CHANGELOG.md`에 기록할 때 사용합니다. 문서별 역할은 [문서 운영 정책](../documentation_policy.md)에서 정의합니다.

🟡 이 템플릿 파일 하단의 푸터는 템플릿 자체에 적용된 것입니다. 복사한 문서의 푸터는 대상 저장소의 규칙을 따릅니다. 푸터를 금지하는 저장소에서는 푸터를 제거하고, 날짜는 복사한 날짜로 갱신합니다.

## 1. 사용 방법

새 저장소에는 아래 골격을 복사하여 `CHANGELOG.md`로 사용합니다.

```markdown
# Changelog

이 프로젝트의 주요 변경 사항을 기록합니다.

---

## [0.1.0] - YYYY-MM-DD

### Added

- 초기 문서 구조 추가.
```

기존 `CHANGELOG.md`에 항목을 추가할 때는 2장 형식에 맞춰 최신 릴리스를 맨 위에 넣습니다.

🟡 `CHANGELOG.md`에는 목차를 두지 않습니다. 릴리스가 누적되면 목차 유지 비용이 커지고, `[⬆ 목차로 돌아가기]` 링크가 존재하지 않는 앵커를 가리키게 됩니다.

## 2. 릴리스 형식

```markdown
## [MAJOR.MINOR.PATCH] - YYYY-MM-DD

### Added

- 추가한 내용을 작성합니다.

### Changed

- 변경한 내용을 작성합니다.

---
```

- 최신 릴리스를 파일 위쪽에 둡니다.
- 릴리스 사이에 `---`를 넣습니다.
- 해당 릴리스에 없는 변경 유형은 섹션 자체를 생략합니다.

### 버전 번호

| 자리  | 올리는 기준                                 |
|-------|---------------------------------------------|
| MAJOR | 디렉토리 구조 변경, 기존 링크가 깨지는 변경 |
| MINOR | 문서·정책·기능 추가, 하위 호환 변경         |
| PATCH | 오타·링크·사실 오류 수정만 포함             |

날짜만으로 구분이 충분한 저장소는 버전 번호 없이 `## [YYYY-MM-DD]` 형식을 사용할 수 있습니다. 저장소 안에서 한 가지 방식으로 통일합니다.

## 3. 변경 유형

| 유형         | 기록 대상                       | 예시                            |
|--------------|---------------------------------|---------------------------------|
| `Added`      | 새로 추가된 문서·기능·규칙      | 새 가이드 문서 추가             |
| `Changed`    | 기존 내용의 변경·이동·구조 조정 | 디렉토리 rename, 정책 갱신      |
| `Fixed`      | 오류 수정                       | 오타, 깨진 링크, 사실 오류 정정 |
| `Removed`    | 삭제된 문서·기능·규칙           | 구버전 백업 파일 제거           |
| `Deprecated` | 제거 예정 안내                  | 이관 예정인 중앙 profile        |
| `Security`   | 보안 관련 변경                  | 자격증명 취급 방식 변경         |

- 위 유형 외의 이름을 새로 만들지 않습니다.
- 한 항목이 여러 유형에 걸치면 주된 유형 하나를 선택합니다.

## 4. 작성 규칙

- 완료된 변경만 기록합니다. 예정 작업은 `TODO.md`에 둡니다.
- 명사형 또는 `~함` 형태로 간결하게 작성하고 마침표를 붙입니다.
- 변경 대상 파일·디렉토리 경로를 백틱으로 명시합니다.
- 사실 정정은 무엇이 어떻게 틀렸는지 기록합니다. 근거 출처가 있으면 함께 남깁니다.
- 커밋 해시를 나열하지 않습니다. 변경의 의미를 사람이 읽을 수 있게 씁니다.
- 개인 경로, 내부 IP, 자격증명은 기록하지 않습니다.

### `TODO.md`와의 관계

완료된 `TODO.md` 항목은 제거하고 그 내용을 `CHANGELOG.md`에 옮깁니다. 두 문서에 같은 항목을 동시에 남기지 않습니다.

## 5. 예시

```markdown
## [1.2.0] - YYYY-MM-DD

### Added

- 저장소별 규칙을 정의하는 `.governance/` 체계와 우선순위 정책 추가.
- `templates/governance_template.md` 추가.

### Changed

- `README.md`의 저장소 profile 설명을 `.governance/` 체계 기준으로 갱신.

### Fixed

- 문서 표에서 소관 기관을 약어만 표기하던 부분을 풀네임 병기로 정정.

---

## [1.1.1] - YYYY-MM-DD

### Fixed

- 깨진 내부 링크 3건 수정.
- 구버전 백업 파일이 저장소에 추적되던 문제 해결.
```
