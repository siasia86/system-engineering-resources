# README Template

저장소 또는 디렉토리의 `README.md`를 작성할 때 사용합니다. 푸터·배지 규칙은 `readme-template` skill에서 정의하며, 이 템플릿은 본문 구조를 다룹니다. 문서별 역할은 [문서 운영 정책](../documentation_policy.md)에서 정의합니다.

🟡 이 템플릿 파일 하단의 푸터는 템플릿 자체에 적용된 것입니다. 복사한 문서의 푸터는 대상 저장소의 규칙을 따릅니다. 푸터를 금지하는 저장소에서는 푸터를 제거하고, 날짜는 복사한 날짜로 갱신합니다.

## 1. 사용 방법

```bash
cp templates/readme_template.md <target>/README.md
```

복사 후 2장의 순서대로 섹션을 구성하고, 이 문서의 1·3·4장은 제거합니다.

저장소 규모에 따라 구성 요소를 선택합니다. 문서 3개짜리 디렉토리에 목차와 디렉토리 구조를 넣으면 본문보다 형식이 길어집니다.

## 2. 문서 골격

아래 순서로 구성합니다. 각 항목의 필수 여부는 3장을 참고합니다.

```text
# <저장소 또는 디렉토리 이름>

<무엇을 담고 있는지 한 문장>

## 목차                      <- H2 4개 이상일 때만
  표 형태, H2만 포함

---

## 1. 시작하기               <- 실행·설치 절차가 있을 때만
  전제 조건
  실행 명령 (bash 코드 블록)

## 2. 구조                   <- 하위 디렉토리 3개 이상일 때만
  트리 문자로 표현 (text 코드 블록)

## 3. 문서 목록              <- 문서 저장소인 경우
  표: 문서 링크 + 한 줄 설명

## 저장소 규칙               <- .governance/ 가 있을 때만
  .governance/GOVERNANCE.md 링크

## 참고 자료                 <- 외부 출처가 있을 때만
  목록 형태, 별점 표기

<푸터 — 저장소 규칙에 따름>
```

## 3. 구성 요소

| 구성 요소           | 필수   | 내용                              |
|---------------------|--------|-----------------------------------|
| H1 제목             | ✅     | 저장소 또는 디렉토리 이름         |
| 한 줄 요약          | ✅     | 무엇을 담고 있는지 한 문장        |
| 목차                | 선택   | H2가 4개 이상일 때 표 형태로 추가 |
| 시작하기            | 선택   | 실행·설치 절차가 있는 저장소만    |
| 디렉토리 구조       | 선택   | 하위 디렉토리가 3개 이상일 때     |
| 문서 인덱스         | 선택   | 문서 저장소인 경우 표로 정리      |
| `.governance/` 링크 | 조건부 | 저장소별 규칙이 있으면 필수       |
| 참고 자료           | 선택   | 외부 출처가 있으면 별점과 함께    |
| 푸터                | 조건부 | 저장소 규칙에 따름                |

### `.governance/` 링크를 두는 이유

`.governance/`는 숨김 디렉토리이므로 저장소를 탐색해도 눈에 띄지 않습니다. 저장소별 규칙이 있으면 `README.md`에서 링크하여 발견성을 확보합니다.

## 4. 작성 규칙

- H1은 문서당 1개만 사용합니다.
- H2가 4개 이상이면 목차를 표로 추가합니다.
- 목차에는 H2만 포함합니다. H3 이하를 섞지 않습니다.
- 표는 한글 폭 2칸 기준으로 정렬합니다.
- 디렉토리 구조는 트리 문자(`├──`, `└──`, `│`)를 사용합니다.
- 실행 절차는 복사해서 바로 쓸 수 있는 형태로 작성합니다.
- 개인 경로, 내부 IP, 자격증명은 기록하지 않습니다.
- 외부 링크는 별점을 함께 표기합니다.

### 하위 디렉토리 `README.md`

하위 디렉토리에도 `README.md`를 두면 해당 범위의 인덱스가 됩니다. 상위 `README.md`의 내용을 반복하지 않고, 그 디렉토리에 한정된 정보만 작성합니다.

### 문서 목록 유지

문서 목록을 표로 두면 문서 추가·삭제 시 갱신이 필요합니다. 자동 검사가 있는 저장소는 그 검사에 맞춰 형식을 유지합니다.
