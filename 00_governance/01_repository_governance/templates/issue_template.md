# ISSUE Template

재현 절차나 원인 분석이 필요한 문제를 루트 `ISSUE.md`에 기록할 때 사용합니다.

## 목차

| 섹션                                                         |
|--------------------------------------------------------------|
| [1. 요약](#1-요약) / [2. 영향](#2-영향) / [3. 재현](#3-재현) |
| [4. 원인](#4-원인) / [5. 해결](#5-해결) / [6. 검증](#6-검증) |

---

## 1. 요약

- 제목:
- 상태: `open`
- 우선순위: `low` / `medium` / `high`

## 2. 영향

- 영향을 받는 문서·스크립트·환경을 작성합니다.
- 보안 또는 데이터 손실 영향이 있으면 명시합니다.

## 3. 재현

```text
재현 명령과 기대 결과를 작성합니다.
```

## 4. 원인

- 확인된 원인을 작성합니다.
- 미확인 내용은 추정으로 표시하지 않고 미확인 상태로 남깁니다.

## 5. 해결

- [ ] 해결 방법을 작성합니다.
- [ ] 관련 TODO 또는 PLAN을 갱신합니다.

## 6. 검증

```bash
# 수정 후 실행한 검증 명령을 작성합니다.
```

- [ ] 재현되지 않음.
- [ ] 회귀 검사 통과.
- [ ] CHANGELOG 기록 여부 확인.
