# lsof 공식 참조 노트

## 1. lsof 개요

### 공식 소스

| 소스   | URL                                               | 용도               |
|--------|---------------------------------------------------|--------------------|
| lsof.8 | https://man7.org/linux/man-pages/man8/lsof.8.html | 옵션, FD/TYPE 설명 |
| GitHub | https://github.com/lsof-org/lsof                  | 최신 버전 확인     |

### 검증된 사실 (2026-08-01)

| 항목             | 값                                                                                    | 출처       |
|------------------|---------------------------------------------------------------------------------------|------------|
| 최신 stable 버전 | 4.99.7 (2026-06-16)                                                                   | GitHub API |
| 기본 동작        | 인수 없이 실행 시 모든 열린 파일 목록 출력                                            | lsof.8     |
| 기본 필터 조합   | 여러 옵션 지정 시 OR 조건 (AND 필요 시 `-a` 사용)                                     | lsof.8     |
| 그룹 옵션 표기   | `-Fn`처럼 단일 대시 뒤 문자 묶음 사용 가능 (단, `+|-M` 등 접두사 다른 옵션 혼합 불가) | lsof.8     |

## 2. 주요 옵션 (lsof.8 man page 기반)

### 공식 소스

| 소스   | URL                                               | 용도      |
|--------|---------------------------------------------------|-----------|
| lsof.8 | https://man7.org/linux/man-pages/man8/lsof.8.html | 옵션 목록 |

### 검증된 사실 (2026-08-01)

| 옵션        | 동작                                                | 출처   |
|-------------|-----------------------------------------------------|--------|
| `-p <s>`    | 프로세스 PID 지정 (콤마 구분, `^pid`로 제외)        | lsof.8 |
| `-i [i]`    | 인터넷 소켓 파일 목록 출력 (주소 지정 가능)         | lsof.8 |
| `-u <s>`    | 사용자 지정 (콤마 구분, `^user`로 제외)             | lsof.8 |
| `-c <c>`    | 명령어 이름 지정 (시작 문자열 또는 `/regex/`)       | lsof.8 |
| `-a`        | 여러 옵션을 OR 대신 AND로 결합                      | lsof.8 |
| `-n`        | 네트워크 주소 숫자로 출력 (DNS 역조회 안 함)        | lsof.8 |
| `-P`        | 포트 번호 숫자로 출력 (서비스명 변환 안 함)         | lsof.8 |
| `-t`        | PID만 출력 (스크립팅용)                             | lsof.8 |
| `+d <dir>`  | 디렉토리의 열린 파일 검색 (비재귀)                  | lsof.8 |
| `+D <dir>`  | 디렉토리의 열린 파일 검색 (재귀)                    | lsof.8 |
| `-F <f>`    | 출력 필드 지정 (스크립팅용)                         | lsof.8 |
| `-U`        | UNIX 도메인 소켓 파일만 출력                        | lsof.8 |
| `-b`        | 블로킹 커널 호출 회피                               | lsof.8 |
| `+\|-r [t]` | 반복 실행 모드 (`+r`: 파일 없을 때까지, `-r`: 무한) | lsof.8 |
| `-s [p:s]`  | 프로토콜:상태 필터 (`-i`와 함께 사용)               | lsof.8 |

## 3. 출력 필드 (lsof.8 man page 기반)

### 검증된 사실 (2026-08-01)

| 컬럼명   | 의미                                               | 출처   |
|----------|----------------------------------------------------|--------|
| COMMAND  | 프로세스 명령어 이름                               | lsof.8 |
| PID      | 프로세스 ID                                        | lsof.8 |
| USER     | 프로세스 소유자                                    | lsof.8 |
| FD       | 파일 디스크립터 (cwd/txt/mem/숫자r/숫자w/숫자u 등) | lsof.8 |
| TYPE     | 파일 타입 (REG/DIR/CHR/FIFO/IPv4/IPv6/unix 등)     | lsof.8 |
| DEVICE   | 장치 번호                                          | lsof.8 |
| SIZE/OFF | 파일 크기 또는 오프셋                              | lsof.8 |
| NODE     | inode 번호 또는 프로토콜                           | lsof.8 |
| NAME     | 파일명 또는 네트워크 주소                          | lsof.8 |

## 4. deprecated / 주의사항

| 항목                         | 상태                                                     | 출처   |
|------------------------------|----------------------------------------------------------|--------|
| `-i` 없이 `-u` + `-a` + `-U` | AND 조건으로 UNIX 소켓 + 특정 사용자만 필터링 가능       | lsof.8 |
| `+|-M` 혼합 표기             | 접두사(`+`, `-`)가 다른 옵션을 같은 그룹으로 묶으면 오류 | lsof.8 |
