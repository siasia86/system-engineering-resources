# Software Testing 공식 참조 노트

## 1. 확인 범위

범용 테스트 케이스와 테스트 설계 문서의 공통 기준을 2026-09-15에 ISTQB 공식 페이지와 공식 용어집 기준으로 확인했습니다.

## 2. 공식 기준

ISTQB Certified Tester Foundation Level(CTFL) v4.0은 소프트웨어 테스트에서 사용하는 기본 용어와 개념을 다루며, 테스트 원칙·테스트 활동·테스트웨어·테스트 역할·테스트 레벨·테스트 유형·테스트 설계를 포함합니다.

다음 문서군의 공통 용어와 기본 구조는 이 참조 노트를 우선 대조합니다.

- 테스트 케이스 구성과 기대 결과
- 테스트 시나리오와 테스트 설계
- 테스트 레벨·테스트 유형
- 테스트 위험·우선순위·추적성
- 테스트 데이터와 테스트웨어

## 3. 적용 범위와 제한

이 노트는 여러 테스트 개념 문서가 공유하는 기본 출처입니다. Property-based Testing, Mutation Testing, Fault Injection, 동시성 테스트처럼 별도 도구·표준·프로젝트 공식 문서가 필요한 주제는 본문 문서에서 추가 공식 출처를 연결합니다.

README와 문서 목록 파일은 기술 주장을 위한 문서가 아니므로 이 노트의 참조 대상에서 제외할 수 있습니다.

## 4. 검증 원칙

- 공식 용어의 정의를 임의로 확장하지 않습니다.
- 테스트 기법의 효과를 절대적인 수치나 보장으로 표현하지 않습니다.
- 출처가 없는 커버리지 목표·성능 수치·결함 감소율을 단정하지 않습니다.
- 본문에서 사용하는 전문 용어가 이 노트의 범위를 벗어나면 별도 공식 출처를 추가합니다.
