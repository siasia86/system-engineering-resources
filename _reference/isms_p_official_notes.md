## 3. 인프라 관련 핵심 항목

### 2.5 인증 및 권한관리

| 항목  | 명칭                   | 인프라 핵심 확인사항                         |
|-------|------------------------|----------------------------------------------|
| 2.5.1 | 사용자 계정 관리       | 공유 계정 금지, 퇴직자 계정 즉시 삭제        |
| 2.5.2 | 사용자 식별            | 고유 식별자 부여, root 직접 로그인 제한      |
| 2.5.3 | 사용자 인증            | SSH 키 인증, 2FA, 패스워드 복잡도            |
| 2.5.4 | 비밀번호 관리          | 90일 변경, 이전 5개 재사용 금지, 초기값 변경 |
| 2.5.5 | 특수 계정 및 권한 관리 | root/admin 최소화, sudo 로그, 권한 분리      |

|-------|-----------------------|-------------------------------------------------|
| 2.6.1 | 네트워크 접근통제     | 영역 분리(DMZ/서버팜/DB), ACL, 불필요 포트 차단 |
| 2.6.2 | 정보시스템 접근통제   | OS 파일 퍼미션, 불필요 서비스 제거, root 제한   |

## 4. 파일 퍼미션 관련 매핑 (777 사례)

웹 디렉토리 777 + root:root 상태에서 위반 가능한 항목:

| 항목   | 위반 사유                                        | 심각도 |
|--------|--------------------------------------------------|--------|
| 2.6.2  | OS 파일/디렉토리 접근 권한 과다 (최소 권한 위반) | 상     |
| 2.10.3 | 공개서버 웹 디렉토리 권한 관리 미흡              | 상     |
| 2.9.1  | 누구나 변경 가능 → 비인가 변경 통제 불가         | 중     |
| 2.9.4  | 로그 파일 포함 시 무결성 보장 불가               | 상     |
| 2.5.5  | root 소유로만 운영 → 권한 분리 미흡              | 중     |

### 권장 조치

| 대상              | 현재     | 권장              | 소유자 |
