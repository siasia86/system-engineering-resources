## Layer 3 공격 (네트워크 계층)

### 1. IP Flood
**설명:** 대량의 IP 패킷으로 네트워크 대역폭 소모  
**특징:**
- 소스 IP 위조 가능
- 다양한 프로토콜 사용 (TCP, UDP, ICMP)
- 라우터 및 방화벽 과부하 유발

### 2. ICMP Flood (Ping Flood)
**설명:** ICMP Echo Request 패킷 대량 전송  
**특징:**
- 간단한 구현
- 네트워크 대역폭 소모
- 서버 CPU 리소스 고갈

### 3. Smurf Attack
**설명:** 브로드캐스트 주소로 ICMP 전송하여 증폭 효과  
**특징:**
- 소스 IP를 피해자로 위조
- 브로드캐스트 도메인의 모든 호스트가 응답
- 증폭 비율: 1:N (N = 브로드캐스트 도메인 크기)

### 4. Fraggle Attack
**설명:** Smurf의 UDP 버전, UDP Echo 서비스 악용  
**특징:**
- UDP 포트 7 (Echo) 또는 19 (Chargen) 사용
- 브로드캐스트를 통한 증폭
- 현재는 거의 사용되지 않음

### 5. Land Attack
**설명:** 소스와 목적지 IP가 동일한 패킷 전송  
**특징:**
- 시스템 혼란 유발
- 무한 루프 생성 가능
- 현대 시스템에서는 효과 제한적

### 6. Teardrop Attack
**설명:** 조각난 IP 패킷의 오버랩으로 시스템 크래시 유발  
**특징:**
- IP 프래그먼테이션 악용
- 메모리 오버플로우 유발
- 구형 시스템에 효과적

## Layer 4 공격 (전송 계층)

### 1. SYN Flood
**설명:** TCP 3-way handshake 악용하여 연결 테이블 고갈  
**특징:**
- 가장 일반적인 DDoS 공격
- 서버 연결 큐 고갈
- 소스 IP 위조로 추적 어려움

### 2. ACK Flood
**설명:** 대량의 ACK 패킷으로 방화벽/라우터 과부하  
**특징:**
- Stateful 방화벽 우회 시도
- 연결 추적 테이블 고갈
- 정상 연결처럼 보임

### 3. FIN Flood
**설명:** FIN 패킷 대량 전송으로 연결 종료 처리 과부하  
**특징:**
- 연결 종료 프로세스 악용
- 서버 리소스 소모
- 로그 분석 어려움

### 4. RST Flood
**설명:** RST 패킷으로 기존 연결 강제 종료  
**특징:**
- 정상 연결 중단
- 서비스 가용성 저하
- 연결 상태 혼란 유발

### 5. PSH+ACK Flood
**설명:** PSH와 ACK 플래그 조합으로 즉시 처리 요구  
**특징:**
- 우선순위 높은 패킷으로 인식
- CPU 리소스 집중 소모
- 버퍼 오버플로우 유발 가능

### 6. URG Flood
**설명:** URG 플래그로 긴급 데이터 처리 요구  
**특징:**
- 긴급 포인터 처리 오버헤드
- 시스템 우선순위 혼란
- 특정 애플리케이션 타겟

### 7. UDP Flood
**설명:** 대량의 UDP 패킷으로 대역폭 및 리소스 소모  
**특징:**
- 연결 없는 프로토콜 악용
- ICMP Port Unreachable 응답 유발
- 다양한 포트 타겟 가능

### 8. TCP Window Attack
**설명:** TCP 윈도우 크기 조작으로 데이터 전송 중단  
**특징:**
- 윈도우 크기를 0으로 설정
- 데이터 전송 블록
- 연결 유지하면서 서비스 중단

### 9. TCP Sequence Attack
**설명:** 시퀀스 번호 조작으로 연결 혼란  
**특징:**
- 패킷 순서 혼란
- 재전송 요구 증가
- 네트워크 효율성 저하

## Layer 7 공격 (애플리케이션 계층)

### 1. HTTP Flood (GET/POST)
**설명:** 정상적인 HTTP 요청을 대량 전송  
**특징:**
- 웹 서버 리소스 고갈
- 데이터베이스 과부하
- 캐시 우회 가능

### 2. Slowloris
**설명:** HTTP 헤더를 천천히 전송하여 연결 유지  
**특징:**
- 최소 대역폭으로 최대 피해
- 서버 스레드 고갈
- 탐지 어려움

### 3. Slow HTTP POST (R.U.D.Y)
**설명:** POST 데이터를 매우 천천히 전송  
**특징:**
- Content-Length는 크게 설정
- 서버가 완전한 데이터 대기
- 연결 리소스 고갈

### 4. Slow Read Attack
**설명:** 서버 응답을 매우 천천히 읽음  
**특징:**
- TCP 윈도우 크기 조작
- 서버 연결 유지 강제
- 메모리 리소스 고갈

### 5. HTTP Pipelining Attack
**설명:** 하나의 연결로 다수 HTTP 요청 전송   
**특징:**
- 서버 처리 능력 초과
- 응답 순서 혼란
- 캐시 오염 가능

### 6. SSL/TLS Exhaustion
**설명:** SSL 핸드셰이크 과정에서 서버 CPU 고갈  
**특징:**
- 암호화 연산 오버헤드 악용
- 인증서 검증 과부하
- HTTPS 서비스 타겟

### 7. Sockstress
**설명:** TCP 윈도우 크기를 1로 설정하여 극도로 느린 전송  
**특징:**
- 연결당 1바이트씩 전송
- 서버 메모리 고갈
- 장시간 연결 유지

### 8. Recursive GET Attack
**설명:** 재귀적 리소스 요청으로 서버 과부하  
**특징:**
- 복잡한 페이지 요청
- 서버 측 처리 시간 증가
- CPU 및 메모리 집중 소모

### 9. Hash DoS (HashDos)
**설명:** 해시 충돌을 이용한 CPU 소모 공격  
**특징:**
- 해시 테이블 성능 저하
- O(1) → O(n) 성능 변화
- 웹 애플리케이션 파라미터 악용

### 10. XML Bomb (Billion Laughs)
**설명:** XML 엔티티 확장으로 메모리 고갈  
**특징:**
- 지수적 메모리 사용 증가
- XML 파서 과부하
- 웹 서비스 타겟

## 증폭 공격 (Amplification)

### 1. DNS Amplification
**설명:** 작은 DNS 쿼리로 큰 응답 유도  
**특징:**
- 증폭 비율: 1:28\~54
- ANY 쿼리 주로 사용
- 오픈 리졸버 악용

### 2. NTP Amplification
**설명:** NTP monlist 명령으로 대량 응답 유도  
**특징:**
- 증폭 비율: 1:206
- 모니터링 리스트 요청
- 구형 NTP 서버 타겟

### 3. SNMP Amplification
**설명:** SNMP GetBulkRequest로 대량 데이터 요청  
**특징:**
- 증폭 비율: 1:6.3
- 네트워크 장비 타겟
- Community string 필요

### 4. CharGEN Amplification
**설명:** Character Generator 서비스 악용  
**특징:**
- 증폭 비율: 1:358
- UDP 포트 19 사용
- 무한 문자 생성

### 5. QOTD Amplification
**설명:** Quote of the Day 서비스 악용  
**특징:**
- 증폭 비율: 1:140
- UDP 포트 17 사용
- 랜덤 인용구 응답

### 6. RIPv1 Amplification
**설명:** RIP 라우팅 프로토콜 악용  
**특징:**
- 증폭 비율: 1:131
- 라우팅 테이블 요청
- 네트워크 장비 타겟

### 7. NetBIOS Amplification
**설명:** NetBIOS Name Service 악용  
**특징:**
- 증폭 비율: 1:3.8
- Windows 네트워크 타겟
- UDP 포트 137 사용

### 8. LDAP Amplification
**설명:** LDAP 검색 쿼리로 대량 응답 유도  
**특징:**
- 증폭 비율: 1:46\~55
- 디렉토리 서비스 타겟
- 복잡한 검색 쿼리 사용

### 9. Memcached Amplification
**설명:** Memcached stats 명령 악용  
**특징:**
- 증폭 비율: 1:10,000\~51,000
- 가장 강력한 증폭 공격
- UDP 포트 11211 사용

### 10. SSDP Amplification
**설명:** Simple Service Discovery Protocol 악용  
**특징:**
- 증폭 비율: 1:30.8
- UPnP 장치 타겟
- UDP 포트 1900 사용

### 11. WS-Discovery Amplification
**설명:** Web Services Dynamic Discovery 악용  
**특징:**
- 증폭 비율: 1:220
- Windows Vista/7/8 타겟
- UDP 포트 3702 사용

### 12. CoAP Amplification
**설명:** Constrained Application Protocol 악용  
**특징:**
- 증폭 비율: 1:320
- IoT 장치 타겟
- UDP 포트 5683 사용

## 프로토콜별 공격

### 1. SIP Flood
**설명:** Session Initiation Protocol 메시지 대량 전송  
**특징:**
- VoIP 서비스 타겟
- INVITE, REGISTER 메시지 악용
- 통화 품질 저하

### 2. RTSP Flood
**설명:** Real Time Streaming Protocol 요청 대량 전송
**특징:**
- 스트리밍 서버 타겟
- SETUP, PLAY 명령 악용
- 미디어 서비스 중단

### 3. FTP Flood
**설명:** File Transfer Protocol 연결 대량 생성  
**특징:**
- 파일 서버 타겟
- 익명 로그인 악용
- 대역폭 소모

### 4. SMTP Flood
**설명:** Simple Mail Transfer Protocol 메시지 대량 전송  
**특징:**
- 메일 서버 타겟
- 스팸 메일과 유사
- 큐 오버플로우

### 5. IMAP/POP3 Flood
**설명:** 메일 프로토콜 연결 대량 생성  
**특징:**
- 메일 서버 인증 과부하
- 사서함 접근 지연
- 로그인 시도 집중

### 6. SSH Flood
**설명:** SSH 연결 시도 대량 발생  
**특징:**
- 원격 접속 서비스 타겟
- 인증 과정 과부하
- 브루트포스와 유사

### 7. Telnet Flood
**설명:** Telnet 연결 대량 생성  
**특징:**
- 레거시 시스템 타겟
- 터미널 서비스 과부하
- 보안 취약점 악용

## 하이브리드 공격

### 1. Multi-Vector Attack
**설명:** 여러 공격 기법 동시 사용  
**특징:**
- Layer 3/4/7 동시 공격
- 방어 시스템 우회
- 복합적 피해 증대

### 2. Carpet Bombing
**설명:** 특정 네트워크 대역 전체 공격  
**특징:**
- /24 서브넷 전체 타겟
- 콜래터럴 데미지 발생
- ISP 레벨 영향

### 3. Pulse Wave Attack
**설명:** 주기적으로 공격 강도 변화  
**특징:**
- 탐지 시스템 우회
- 자동 완화 시스템 혼란
- 지속적 서비스 영향

### 4. Bit-and-Piece Attack
**설명:** 작은 규모 공격을 여러 소스에서 동시 실행  
**특징:**
- 개별적으로는 정상 트래픽
- 집합적으로 서비스 영향
- 탐지 어려움

## 신종 공격 기법

### 1. AI-Powered DDoS
**설명:** 인공지능을 이용한 적응형 공격  
**특징:**
- 방어 패턴 학습
- 실시간 공격 최적화
- 탐지 회피 능력

### 2. IoT Botnet Attack
**설명:** IoT 장치를 이용한 대규모 봇넷 공격  
**특징:**
- 수백만 장치 동원 가능
- 지리적 분산
- 기본 보안 취약

### 3. CDN Cache Poisoning
**설명:** CDN 캐시를 오염시켜 서비스 중단  
**특징:**
- 캐시 무효화 공격
- 오리진 서버 과부하
- 글로벌 영향

### 4. HTTP/2 Rapid Reset
**설명:** HTTP/2 스트림 리셋 기능 악용  
**특징:**
- 스트림 생성 후 즉시 리셋
- 서버 리소스 고갈
- 최신 웹 서버 타겟

### 5. QUIC Flood
**설명:** QUIC 프로토콜의 연결 설정 과정 악용  
**특징:**
- UDP 기반 HTTP/3 타겟
- 연결 상태 관리 과부하
- 차세대 웹 프로토콜 공격

### 6. WebRTC Flood
**설명:** WebRTC 연결 설정 과정 악용  
**특징:**
- P2P 연결 시도 대량 발생
- STUN/TURN 서버 과부하
- 실시간 통신 서비스 타겟

### 7. GraphQL Query Complexity Attack
**설명:** 복잡한 GraphQL 쿼리로 서버 과부하  
**특징:**
- 중첩된 쿼리 사용
- 데이터베이스 과부하
- API 서버 타겟

### 8. Container Escape DDoS
**설명:** 컨테이너 탈출 후 호스트 시스템 공격  
**특징:**
- 컨테이너 보안 취약점 악용
- 호스트 리소스 직접 공격
- 클라우드 환경 타겟

### 9. Serverless Function Abuse
**설명:** 서버리스 함수를 악용한 공격  
**특징:**
- 함수 실행 비용 증가
- 동시 실행 한계 도달
- 클라우드 서비스 타겟

### 10. 5G Network Slicing Attack
**설명:** 5G 네트워크 슬라이싱 기능 악용  
**특징:**
- 특정 슬라이스 과부하
- 네트워크 품질 저하
- 차세대 통신망 타겟

## 공격 분류별 요약

### 대역폭 소모형 공격
- UDP Flood, ICMP Flood, HTTP Flood
- 네트워크 대역폭 포화
- 높은 트래픽 볼륨 필요

### 리소스 고갈형 공격
- SYN Flood, Slowloris, SSL Exhaustion
- 서버 리소스 (CPU, 메모리, 연결) 고갈
- 상대적으로 낮은 트래픽으로 효과

### 증폭형 공격
- DNS, NTP, Memcached Amplification
- 작은 요청으로 큰 응답 유도
- 반사 공격과 결합

### 애플리케이션 타겟 공격
- HTTP Flood, XML Bomb, Hash DoS
- 특정 애플리케이션 취약점 악용
