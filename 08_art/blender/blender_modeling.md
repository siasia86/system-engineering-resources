# Blender 모델링 기초
<!-- reference: _reference/blender_official_notes.md -->

메시(Mesh)는 정점(Vertex)·모서리(Edge)·면(Face)으로 이루어진 모양 데이터입니다. 이 문서는 메시 구조 → Edit 모드 선택 → 기본 편집 도구 → 정리 작업 → 토폴로지 원칙 → 예제 순서로 메시 모델링의 기초를 정리합니다.

- 기준 판: Blender 5.3.0 (2026-11-26 확인)
- 예제 시험: 2026-11-26, `bpy` 5.3.0 컨테이너에서 정육면체에 돌출·Inset·베벨·나누기·중복 병합·법선 다시 계산·크기 적용·Smooth by Angle을 연산자(`bpy.ops.mesh.*`)로 실행해 정점/모서리/면 수를 확인. 루프 컷·칼처럼 마우스 위치가 필요한 도구와 화면 조작은 실행하지 않았음

## 1. 메시 구조

| 요소   | 설명                                          | Edit 모드 선택 키 |
|--------|-----------------------------------------------|-------------------|
| 정점   | 3D 공간의 점                                  | `1`               |
| 모서리 | 정점 두 개를 잇는 선                          | `2`               |
| 면     | 모서리로 둘러싼 면. 3각형·4각형·다각형(N-gon) | `3`               |
| 법선   | 면이 바라보는 방향(바깥쪽이 앞면)             | -                 |

- 기본 정육면체는 정점 8, 모서리 12, 면 6입니다.
- 객체(Object)는 위치·회전·크기를 가진 그릇이고, 메시 데이터는 그 안의 모양입니다. 여러 객체가 같은 메시 데이터를 함께 쓸 수 있습니다(`Alt+D` 연결 복제).
- 화면 오른쪽 아래 상태 표시줄을 오른쪽 클릭해 `Scene Statistics`를 켜면 정점·면 수가 보입니다.

## 2. 추가와 선택

### 2.1 기본 도형 추가

Object 모드에서 `Shift+A` > `Mesh`로 추가합니다. 추가 직후 왼쪽 아래에 나오는 "Adjust Last Operation" 창(`F9`)에서 크기·분할 수를 바꿉니다. 창을 닫은 뒤에는 바꿀 수 없습니다.

| 도형       | 쓰는 곳                                  |
|------------|------------------------------------------|
| Cube       | 상자·건물·가구 등 대부분의 시작점        |
| Cylinder   | 기둥·컵·바퀴. 꼭짓점 수(Vertices)를 정함 |
| UV Sphere  | 공. 위아래 극점에 삼각형이 모임          |
| Ico Sphere | 고른 삼각형 공. 스컬프팅 시작점          |
| Plane      | 바닥·벽, 면 하나로 시작하는 모델링       |
| Torus      | 고리                                     |

### 2.2 Edit 모드에서 선택

| 키                         | 선택                      |
|----------------------------|---------------------------|
| 왼쪽 클릭                  | 하나                      |
| `Shift` + 왼쪽 클릭        | 추가·빼기                 |
| `Alt` + 왼쪽 클릭          | 루프(한 바퀴 이어진 고리) |
| `Ctrl` + 왼쪽 클릭         | 최단 경로                 |
| `L` / `Ctrl+L`             | 연결된 부분               |
| `Ctrl` + 숫자 패드 `+`·`-` | 넓히기·줄이기             |
| `Alt+Z`                    | 엑스레이(뒤쪽까지 선택)   |

## 3. 편집 도구

아래 정점/모서리/면 수는 기본 정육면체에서 연산자로 실행한 결과입니다.

| 도구      | 키                      | 하는 일                                        | 시험 결과 (정점/모서리/면)                      |
|-----------|-------------------------|------------------------------------------------|-------------------------------------------------|
| 돌출      | `E`                     | 선택 부분을 끌어내 새 면을 만듦                | 윗면을 위로 1 → 12/20/10                        |
| Inset     | `I`                     | 면 안쪽에 테두리 면을 만듦                     | 이어서 윗면 두께 0.2 → 16/28/14                 |
| 베벨      | `Ctrl+B`                | 모서리를 깎아 둥글게, 휠로 분할 수             | 이어서 모든 모서리 폭 0.05·분할 3 → 224/448/226 |
| 나누기    | 오른쪽 클릭 > Subdivide | 선택 모서리를 같은 간격으로 나눔               | 정육면체 전체 1회 → 26/48/24                    |
| 루프 컷   | `Ctrl+R`                | 고리 모양으로 모서리를 하나 더 넣음, 휠로 개수 | 시험하지 않음(마우스 위치 필요)                 |
| 칼        | `K`                     | 직접 선을 그어 자름                            | 시험하지 않음                                   |
| 면 만들기 | `F`                     | 선택한 정점·모서리를 이어 면·모서리 생성       | -                                               |
| 병합      | `M`                     | 선택 정점을 한 점으로                          | -                                               |
| 분리      | `P`                     | 선택 부분을 별도 객체로                        | -                                               |

- 돌출은 원래 윗면을 지우고 옆면 4개와 새 윗면을 만듭니다. 그래서 면 수가 6에서 10이 됩니다.
- 돌출 중 오른쪽 클릭으로 취소해도 돌출 자체는 남고 이동만 취소됩니다. 같은 자리에 겹친 면이 생기므로 `Ctrl+Z`로 되돌립니다.
- 도구를 쓴 직후 `F9`로 값(두께·분할 수·폭)을 숫자로 고칠 수 있습니다.

## 4. 정리 작업

| 작업               | 방법                                   | 시험 결과                                                   |
|--------------------|----------------------------------------|-------------------------------------------------------------|
| 겹친 정점 합치기   | `M` > By Distance (Merge by Distance)  | 메시를 통째로 복제한 뒤 실행하면 원래 수(26/48/24)로 돌아옴 |
| 법선 바깥쪽으로    | `Shift+N` (안쪽은 `Ctrl+Shift+N`)      | 법선을 뒤집은 뒤 실행하면 윗면 법선 z = 1.0으로 복구        |
| 크기 적용          | Object 모드 `Ctrl+A` > Scale           | 크기 (2,1,1) 적용 → 크기 (1,1,1), 정점 x 최대 2.0           |
| 부드럽게 보이기    | Object 모드 오른쪽 클릭 > Shade Smooth | 성공                                                        |
| 각도 기준 부드럽게 | 오른쪽 클릭 > Shade Auto Smooth        | "Smooth by Angle" 지오메트리 노드 모디파이어가 추가됨       |

- 크기를 적용하지 않으면 베벨·Solidify·물리 시뮬레이션이 축마다 다르게 동작합니다. 모델링을 마치면 `Ctrl+A` > `All Transforms` 또는 `Scale`을 적용합니다.
- 법선이 뒤집히면 렌더에서 면이 검게 나오거나 게임 엔진에서 안 보입니다. 뷰포트 Overlays의 `Face Orientation`을 켜면 앞면은 파랑, 뒷면은 빨강으로 보입니다.
- 5.x에서 각도 기준 부드럽게(옛 Auto Smooth)는 메시 설정이 아니라 모디파이어(Smooth by Angle)로 붙습니다.

## 5. 토폴로지 원칙

토폴로지(Topology)는 면이 이어진 흐름입니다. 모양이 같아도 흐름이 나쁘면 변형·UV·서브디비전에서 문제가 납니다.

| 원칙                                    | 이유                                                      |
|-----------------------------------------|-----------------------------------------------------------|
| 4각형(Quad) 위주                        | 루프 선택·루프 컷·서브디비전이 깔끔하게 동작              |
| 다각형(N-gon)은 평평한 곳만             | 굽은 면에 쓰면 서브디비전·변형 때 주름이 생김             |
| 3각형은 눈에 띄지 않는 곳               | 게임용 내보내기 때는 어차피 3각형으로 바뀜                |
| 극점(정점에 모서리 3개·5개 이상) 줄이기 | 서브디비전 때 꼬집힌 자국이 생김                          |
| 변형되는 곳(관절·입)에 루프             | 애니메이션 때 자연스럽게 접힘                             |
| 실제 크기로 만들기                      | 1단위 = 1m(초기값 Metric·미터). 물리·조명·내보내기가 맞음 |

- 서브디비전으로 매끈하게 만들 모델은 모서리 근처에 루프를 하나 더 넣어(지지 루프) 모서리 둥글기를 조절합니다.
- 면 수는 용도에 맞춥니다. 게임 실시간 모델은 적게, 영상 렌더용은 서브디비전으로 늘립니다.

## 6. 예제: 상자에서 컵 만들기

1. `Shift+A` > `Mesh` > `Cylinder`로 원기둥을 추가합니다. 꼭짓점 수(Vertices)는 초기값 32이며 `F9`에서 바꿉니다.
2. `Tab`으로 Edit 모드, `3`으로 면 선택, 윗면을 클릭합니다.
3. `I`로 안쪽 테두리를 만들어 컵 두께를 정합니다.
4. `E`로 아래로 끌어 안쪽을 파냅니다(바닥 두께만큼 남김).
5. `Tab`으로 Object 모드, 오른쪽 클릭 > `Shade Auto Smooth`.
6. Properties > Modifiers에서 Subdivision Surface를 추가해 매끈하게 하고([모디파이어](./blender_modifiers.md)), 테두리가 너무 둥글면 `Ctrl+R`로 지지 루프를 넣습니다.

- 이 예제의 3~4단계는 3절에서 정육면체로 시험한 Inset·돌출과 같은 연산입니다. 원기둥 전체 과정은 화면에서 실행하지 않았습니다.

## 7. 트러블슈팅

| 증상                             | 원인                            | 해결                                 |
|----------------------------------|---------------------------------|--------------------------------------|
| 면이 검게 나오거나 이상하게 비침 | 법선이 안쪽을 향함              | `Shift+N`, Face Orientation으로 확인 |
| 베벨 폭이 축마다 다름            | 객체 크기를 적용하지 않음       | `Ctrl+A` > Scale                     |
| 돌출했는데 모양이 그대로         | 취소해서 같은 자리에 면이 겹침  | `Ctrl+Z`, 또는 `M` > By Distance     |
| 서브디비전 후 표면에 주름·꼬집힘 | 다각형·극점이 굽은 곳에 있음    | 4각형으로 다시 나누고 지지 루프 추가 |
| 루프 선택이 중간에 끊김          | 루프 경로에 3각형·다각형이 있음 | 해당 부분을 4각형으로 정리           |
| 정점 수가 예상보다 많음          | 복제·돌출 취소로 겹친 정점      | `M` > By Distance                    |
