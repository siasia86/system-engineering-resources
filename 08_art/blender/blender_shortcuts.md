# Blender 단축키
<!-- reference: _reference/blender_official_notes.md -->

Blender는 거의 모든 기능에 단축키가 있고, 단축키는 마우스가 올라가 있는 편집기에만 적용됩니다. 이 문서는 초기 설정(왼쪽 클릭 선택, Space 재생)에서 자주 쓰는 키를 상황별로 정리합니다.

- 기준 판: Blender 5.3.0 기본 키맵 "Blender" (2026-11-26 확인)
- 예제 시험: 2026-11-26, `bpy` 5.3.0 컨테이너에서 내장 키맵 정의(`keymap_data/blender_default.py`)를 초기 설정값으로 생성해 표의 키를 모두 대조. 화면에서 직접 눌러 보지는 않았음

## 1. 읽는 법

- `Ctrl+B`는 `Ctrl`을 누른 채 `B`, `Shift` + 가운데 버튼 끌기는 `Shift`를 누른 채 휠 버튼을 누르고 끄는 것입니다.
- "숫자 패드 1"은 키보드 오른쪽 숫자 패드의 키이고, 그냥 `1`은 문자 키 위쪽 숫자 줄의 키입니다. 둘은 다른 기능입니다.
- 같은 키도 모드에 따라 기능이 다릅니다. 예를 들어 `I`는 Object 모드에서 키프레임 넣기, Edit 모드에서 면 안쪽 삽입(Inset)입니다.
- macOS에서 `Ctrl`·`Cmd` 대응은 이 문서에서 확인하지 않았습니다. 메뉴에 표시된 키를 기준으로 합니다.

## 3. 시점

| 키                            | 기능                         |
|-------------------------------|------------------------------|
| 가운데 버튼 끌기              | 시점 회전                    |
| `Shift` + 가운데 버튼 끌기    | 시점 이동                    |
| 휠, `Ctrl` + 가운데 버튼 끌기 | 확대·축소                    |
| 숫자 패드 1 / 3 / 7           | 정면 / 오른쪽 / 위           |
| `Ctrl` + 숫자 패드 1 / 3 / 7  | 뒤 / 왼쪽 / 아래             |
| 숫자 패드 2·4·6·8             | 15도씩 회전(기본 각도)       |
| `Ctrl` + 숫자 패드 2·4·6·8    | 시점 이동                    |
| `Shift` + 숫자 패드 4·6       | 시점 기울이기(Roll)          |
| 숫자 패드 5                   | 원근 ↔ 직교                  |
| 숫자 패드 9                   | 반대편 보기                  |
| 숫자 패드 0                   | 카메라 시점                  |
| 숫자 패드 `.`                 | 선택 대상에 맞춤             |
| `Home`                        | 전체 맞춤                    |
| 숫자 패드 `/`                 | 로컬 뷰(선택 대상만 보기)    |
| 그레이브 키(숫자 1 왼쪽)      | 시점 원형 메뉴               |
| `Shift+B`                     | 영역 끌어 확대               |
| `Z`                           | 표시 방식 원형 메뉴          |
| `Alt+Z`                       | 엑스레이(뒤쪽까지 보기·선택) |
| `Shift+Alt+Z`                 | 오버레이 끄기·켜기           |

- 숫자 패드 2·4·6·8의 회전 각도는 환경설정의 Rotation Angle 값(초기값 15도, 컨테이너 확인)이고, 누르고 있으면 반복합니다.

## 5. 변형

Object 모드와 Edit 모드에서 같습니다.

| 키  | 기능 |
|-----|------|
| `G` | 이동 |
| `R` | 회전 |
| `S` | 크기 |

변형 중에 쓰는 키:

| 키                    | 기능                                          |
|-----------------------|-----------------------------------------------|
| `X` / `Y` / `Z`       | 해당 축으로 제한, 두 번 누르면 지역(Local) 축 |
| `Shift` + `X`·`Y`·`Z` | 해당 축을 빼고 나머지 두 축(평면)으로 제한    |
| 숫자 입력             | 값 지정(예: `G` `Z` `2` = Z축으로 2m)         |
| `Ctrl` 누른 채        | 스냅(격자 등)                                 |
| `Shift` 누른 채       | 미세 조정                                     |
| 왼쪽 클릭, `Enter`    | 확정                                          |
| 오른쪽 클릭, `Esc`    | 취소                                          |

관련 키:

| 키                    | 기능                                  |
|-----------------------|---------------------------------------|
| `Shift+S`             | 스냅 원형 메뉴(커서·선택 대상 맞추기) |
| `Shift+Tab`           | 스냅 켜기·끄기                        |
| `.`                   | 기준점(Pivot) 원형 메뉴               |
| `,`                   | 변형 방향(Orientation) 원형 메뉴      |
| `O`                   | 비례 편집 켜기·끄기                   |
| `Shift+O`             | 비례 편집 감쇠 방식 원형 메뉴         |
| `Shift` + 오른쪽 클릭 | 3D 커서 놓기                          |

- 변형 중 제한 축 키(`X`·`Y`·`Z`)와 숫자 입력은 변형 연산 자체의 동작이라 위 키맵 대조 범위에 넣지 않았습니다(매뉴얼 기준).

## 9. 오른쪽 클릭 선택일 때 바뀌는 키

`Preferences > Keymap`에서 선택 마우스를 Right로 바꾸면 다음 키가 달라집니다(키맵 정의를 두 설정으로 생성해 비교).

| 기능             | 왼쪽 클릭 선택 (초기값) | 오른쪽 클릭 선택    |
|------------------|-------------------------|---------------------|
| 선택             | 왼쪽 클릭               | 오른쪽 클릭         |
| 문맥 메뉴        | 오른쪽 클릭             | `W`                 |
| 루프 선택        | `Alt` + 왼쪽 클릭       | `Alt` + 오른쪽 클릭 |
| 끌어서 바로 이동 | 왼쪽 버튼 끌기          | 오른쪽 버튼 끌기    |

스페이스바 동작은 선택 마우스와 별개 설정입니다(`Preferences > Keymap > Spacebar Action`). 초기값 Play에서는 `Space` 재생·`Shift+Space` 도구 모음이고, Tools로 바꾸면 반대가 됩니다.

## 10. 단축키 찾기·바꾸기

- 메뉴 항목 오른쪽에 단축키가 표시됩니다. 기억나지 않으면 `F3`으로 이름을 검색합니다.
- 메뉴 항목에서 오른쪽 클릭 > `Add to Quick Favorites`로 `Q` 메뉴에 넣습니다.
- 메뉴 항목에서 오른쪽 클릭 > `Assign Shortcut` / `Change Shortcut`으로 키를 바꿉니다. 바꾼 키는 사용자 키맵에 저장됩니다.
- `Preferences > Keymap`에서 다른 키맵 묶음(예: Industry Compatible, 다른 3D 프로그램과 비슷한 배치)을 고르거나, 키맵을 내보내고(Export) 가져올(Import) 수 있습니다.
- 상태 표시줄 왼쪽에 지금 누를 수 있는 마우스·키 안내가 나옵니다.
